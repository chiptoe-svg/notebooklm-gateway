# Roadmap

## Vision
Narrow NotebookLM access for agents: caller-supplied sources in; podcasts, reports, slides, infographics and cited answers out; per-consumer tokens, scopes and quotas; the Google credential never leaves the host.

## Possible
- Video overviews, quizzes, flashcards, mind maps (same job pattern)
- MP3 transcode
- Notebook cleanup / retention
- Push completion to the calling agent instead of polling
- Alert when the Google login stops working
